## ១. គោលបំណង
ធានាថាគ្រប់ចលនាទំនិញ (ចូល/ចេញ) ត្រូវបានកត់ត្រាត្រឹមត្រូវ ទាន់ពេល ក្នុងប្រព័ន្ធ Web App ដើម្បីឲ្យសមតុល្យស្តុកក្នុង Google Sheet ត្រូវនឹងស្តុកជាក់ស្តែង។

## ២. វិសាលភាព
អនុវត្តចំពោះបុគ្គលិកទាំងអស់ដែលទទួល លក់ ឬបញ្ចេញទំនិញពីហាង/ឃ្លាំង។

| តួនាទី | ការទទួលខុសត្រូវ |
|---|---|
| អ្នកគ្រប់គ្រងឃ្លាំង | ពិនិត្យ និងកត់ត្រាស្តុកចូល |
| អ្នកលក់ | កត់ត្រាស្តុកចេញ |
| ម្ចាស់ហាង | ពិនិត្យ Email ជូនដំណឹង អនុម័តការបញ្ជាទិញ |

## ៤. នីតិវិធីស្តុកចូល (Stock In)
1. **ទទួលទំនិញ** — ផ្ទៀងផ្ទាត់វិក្កយបត្រអ្នកផ្គត់ផ្គង់ ជាមួយការបញ្ជាទិញ (ឈ្មោះ, បរិមាណ, ថ្ងៃផុតកំណត់)។
2. **ពិនិត្យគុណភាព** — ទំនិញខូច ឬខុស ត្រូវបដិសេធ ហើយកត់ចំណាំលើវិក្កយបត្រ។
3. **បើក Web App** → ទំព័រ «ស្តុកចូល/ចេញ» → ជ្រើស **ស្តុកចូល**។
4. **បំពេញ Form**៖ ទំនិញ (SKU), បរិមាណ, អ្នកផ្គត់ផ្គង់, ចំណាំ (លេខវិក្កយបត្រ)។
5. **ចុច «រក្សាទុក»** → ពិនិត្យសារ «ជោគជ័យ» និងសមតុល្យថ្មី។
6. **រៀបទំនិញ** ទៅធ្នើ តាមគោលការណ៍ FIFO (ចូលមុន ចេញមុន)។
7. **រក្សាវិក្កយបត្រ** ក្នុងឯកសារតាមខែ។

## ៥. នីតិវិធីស្តុកចេញ (Stock Out)
1. **ពេលលក់ ឬបញ្ចេញ** — បើក Web App → «ស្តុកចូល/ចេញ» → ជ្រើស **ស្តុកចេញ**។
2. **បំពេញ Form**៖ ទំនិញ, បរិមាណ, មូលហេតុ (លក់ / ខូច / ផុតកំណត់ / កែតម្រូវ), ចំណាំ។
3. **ចុច «រក្សាទុក»** — ប្រព័ន្ធនឹងបដិសេធ បើបរិមាណលើសសមតុល្យ។ បើបដិសេធ ត្រូវរាប់ស្តុកឡើងវិញ ហើយរាយការណ៍ទៅអ្នកគ្រប់គ្រងឃ្លាំង។
4. **ទំនិញខូច/ផុតកំណត់** — ថតរូប ហើយផ្ញើទៅម្ចាស់ហាងមុនបោះចោល។
5. **កត់ខុស** — កុំកត់ប្រតិបត្តិការផ្ទុយដើម្បីកែ។ ជូនដំណឹងម្ចាស់ហាង ដើម្បី **លុបចោល** ប្រតិបត្តិការនោះក្នុង Stock Card (ត្រូវមានមូលហេតុ) ហើយកត់ថ្មីឲ្យត្រូវ។

> បុគ្គលិកម្នាក់ៗចូលគណនីដោយ **PIN ផ្ទាល់ខ្លួន** — កុំប្រើ PIN អ្នកដទៃ។ ឈ្មោះអ្នកកត់ត្រូវបានរក្សាទុកក្នុងគ្រប់ប្រតិបត្តិការ។

## ៦. ការជូនដំណឹងស្តុកជិតអស់
1. ពេលសមតុល្យ ≤ ស្តុកអប្បបរមា Apps Script ផ្ញើ Email ទៅ `AlertEmail` ភ្លាមៗ និងរៀងរាល់ព្រឹក ម៉ោង ៨:០០។
2. ម្ចាស់ហាងពិនិត្យ ហើយអនុម័តការបញ្ជាទិញក្នុងរយៈពេល ២៤ ម៉ោង។
3. អ្នកគ្រប់គ្រងឃ្លាំងបញ្ជាទិញពីអ្នកផ្គត់ផ្គង់ តាមបរិមាណណែនាំក្នុង Email។

## ៧. ការរាប់ស្តុក និងរបាយការណ៍
- **ថ្ងៃអាទិត្យ ម៉ោង ៧:០០ មុនបើកហាង** — បើកទំព័រ **«រាប់ស្តុក»** → បញ្ចូលចំនួនរាប់បានជាក់ស្តែង → ពិនិត្យ «ខុសគ្នា» → ចុច «រក្សាទុកការរាប់ស្តុក»។ ប្រព័ន្ធបង្កើតប្រតិបត្តិការ «កែតម្រូវ» ដោយស្វ័យប្រវត្តិ។ ភាពខុសគ្នាលើស $5 ត្រូវរាយការណ៍ទៅម្ចាស់ហាង។
- **រៀងរាល់ថ្ងៃ** — ម្ចាស់ហាងពិនិត្យ **«ផ្ទាំងគ្រប់គ្រង»** (ស្តុកចេញថ្ងៃនេះ · ទំនិញត្រូវបញ្ជាទិញ · នៅសល់ប្រហែល X ថ្ងៃ)។
- **ចុងខែ** — ទំព័រ **«របាយការណ៍»** → «ខែនេះ» → Export CSV ឬ Print/PDF ទុកជាឯកសារ។
- **ថ្ងៃទី ១ នៃខែ** — ប្រព័ន្ធផ្ញើរបាយការណ៍ស្តុកប្រចាំខែទៅម្ចាស់ហាង។
